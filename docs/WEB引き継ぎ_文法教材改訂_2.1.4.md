# ネパール語アプリ 文法教材改訂の引き継ぎ

文法教材と例題を再構成した情報。教材・音声セット1205は既存2.1.3と2.1.4の両方に配信。前回の714例文という文法モードの数値は、改訂版にはそのまま使用しない。

## 変更内容

- 本編34テーマと付録A/Bの36項目を維持。
- 人称を替えただけの反復例題を整理。改訂版の練習例題は528文。本編384文、活用参照用の付録144文。
- 会話モードの既存1,800文は変更なし。会話＋文法の練習例文合計は2,328文。
- 教材内の説明用例、疑問詞の質問と返答、活用表は、上記練習例題数とは別に収録。教材内の表と練習例題を重複加算しない。
- 例題ごとに本文、読み、語・形の意味、文のしくみを教材にも収録。
- 後置詞を基本・同伴と所持・方向と位置・範囲・関係表現に整理。テーマ11、25、26、27、28、32で学ぶ用法も明示。
- 疑問詞は基本形だけでなく、誰に・誰の・誰と、どこから・いつまで、何人・何個・何時などの組み合わせと質問・返答を説明。
- हो・छの基本6人称の肯定・否定、हुन्छ、動作動詞の活用表を教材内で確認できるようにした。
- 基本の彼・彼女はउहाँ、彼ら・彼女らはउहाँहरू。動詞も敬意形に統一。उ・उनीの用法と活用の比較はテーマ7で扱う。
- 人称・敬意はテーマ7で集約。उ・उनीを彼／彼女と機械的に分けず、उहाँも含め敬意と動詞の形を説明。
- テーマ29にजो・जुन・जे・जसले・जसलाई・जसको、जहाँ・जता、जब・जहिले、जसरी・जति・जस्तो・जत्रो等を収録。疑問詞や条件表現との違いも説明。
- 例題の辞書は578表層語、日本語・英語各2,006文脈。日英は同じ構成と範囲。

## 教材解説の拡充（教材1205）

全36項目を日英で拡充。基本解説の日本語本文は各約700〜1,000字（活用表や全体比較などは別）。「何を伝えるか」「用語と型」「文を作る順番」「例文の分解」「否定・疑問と類似表現」「理由付きの確認問題」を備え、文法用語を知っている前提で進めない。

हुनुの辞書形と3系統を区別し、テーマ1＝हो（正体・職業・種類）、テーマ2＝छ（存在・居場所）、テーマ3＝छ（性質・状態）、テーマ4＝हुन्छ（ふだん・条件・出来事・変化）と明示。各該当教材の中で、対応表・比較例・6人称の肯定否定・敬称では形が重なることを説明。付録Bで復習できる。

この更新は教材解説のみ。例文528文・辞書・既存音声を変更せず、アプリの再ビルドもなし。教材の詳しさを紹介する際は、音声付き例題と、教材内の追加説明用の文を重複して数えない。

## 読みやすい教材レイアウト（教材1206）

全36項目の日英教材を、要点カード→例文1つ→3ステップ→短い注意点→確認問題の順に整理。हो・छ・हुन्छの3系統、基本6人称、手順番号、重要な形は太字で強調する。長い解説は「もっと知りたいときに」へ移し、短い段落へ分割。同じ規則を各例題で繰り返していた部分を整理し、例文ごとの説明は残す。

黄色の注意枠と警告記号は教材で使用しない（ユーザーの希望）。注意点も通常の文章・見出し・太字で伝える。既存のgoal/h/p/tableと太字表示だけを使い、殻・例文・辞書・録音は変更せずデータ配信する。

## 色で役割が分かる学習教材（アプリ2.1.5／教材1207）

要点は青、例文は緑、手順は紫、注意は淡い赤、確認問題は青緑。例文カードはネパール語を大きく、手順の数字は丸いバッジで表示。注意を含め黄色や警告記号は使わない。色だけに頼らず見出し・太字・番号でも役割を伝える。

従来の表示処理は文字色・背景が固定だったため、この表示対応は殻の変更となる。2.1.5を既存のios-build-nepali.yml（ios、submit=true）でビルドし、開始後は追跡しない。TestFlightへのビルド開始と到着・一般公開は区別する。旧アプリは教材1207を従来の見た目で安全に読めるが、カラー表示は2.1.5導入後。

以後は教材のpresentation.tone（blue/green/violet/rose/teal）、role、join、rowTonesで用意した配色と表示を指定する。通常の教材・色指定の変更はデータ配信だけで行う。音声・例文・辞書は変更していない。配色のない教材や他アプリは従来の表示を維持する。

検証：4プロジェクトのTypeScript、実際の表示部品の色・番号・旧表示フォールバック、5配色の文字コントラスト4.5:1以上、幅390pxおよび320px/文字1.4倍のブラウザー描画と寸法測定。実機確認の代わりとはしない。
