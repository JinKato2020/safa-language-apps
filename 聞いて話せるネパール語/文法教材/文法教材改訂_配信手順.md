# 文法教材改訂の配信と確認

アプリ2.1.4以降の文法教材パックv3。既存録音は保持し、新規録音は独立IDで追加する。並び替え後の例題と録音の対応を明示する。旧v2の本文・音声を置き換えない。

通常の教材・音声更新ではアプリをビルドしない。詳しくは `docs/教材配信運用_ビルド不要.md` を参照。

## 正本

- 教材の説明・用例・練習選定：`scripts/revise_grammar_curriculum.py`
- 新しい語・形の読みと意味：`文法教材/grammar_v3_lexicon.tsv`
- 既存録音の本文と訳の固定台帳：`文法教材/grammar_recording_texts_v2.json`
- 生成・同期：`scripts/build_grammar_revision.py`
- 実際のローダーを使う検証：`scripts/verify_grammar_revision.cjs`
- 出力：日英の教材MarkdownとgrammarGuide JSON、CSV、grammarExamples、grammarThemes、日英辞書、grammarAudioRefs、日英overlay、coreとcatalog。

## 作業の流れ

1. リポジトリ直下の `.work-grammar-redesign/live` に、現在の `packs-appa-v2` のcore.json、overlay-ja.json、overlay-en.json、catalog.jsonを取得する。既存の録音台帳と、音声ZIPのSHA256が検証結果の値に合うことを確認する。
2. バンドルのPythonで `聞いて話せるネパール語/scripts/build_grammar_revision.py` を実行する。`.work-grammar-redesign/release` に配信JSONができる。音声の生成・再圧縮はしない。
3. バンドルのNodeで `聞いて話せるネパール語/scripts/verify_grammar_revision.cjs` を実行する。日本語・英語、新規本文・旧キャッシュ、本文と録音の一致、新規例題の無音、パック版不一致の拒否、聞き流しの前後移動と無音ループの停止を確認する。
4. `npm run tsc:all` を実行する。
5. Excelはartifact-toolで「v2文法例文」を更新し、既存書式と他シートを保持する。`scripts/preserve_curriculum_workbook.py` はartifactで書いたセル値だけを既存ワークブックへ移す修復工程。中間ファイルが必要なため、スクリプト内の前提を確認する。
6. `packs-appa-v3` にcore、日英overlay、旧版とSHA256一致の音声ZIP3本を置く。catalogを最後に公開する。ダウンロードしたJSON・音声資産のダイジェストとローカル出力を照合する。
7. アプリの変更は従来のGitHub Actions `ios-build-nepali.yml` でビルドしTestFlightへ送る。版番号とrun-nameを一致させる。App Store審査提出・一般公開とは区別する。ユーザーの指示によりビルドは開始後追跡しない。

## 音声の重要な条件

`grammarAudioRefs` は改訂後の例題IDから、固定台帳の録音IDを指す。nullの例題には音声を再生しない。新規の例題IDと同じ番号の旧録音を推測で使わない。

将来、新規音声を作るときは、固定台帳が参照する既存録音を上書きしない。例題の現在位置をそのまま録音IDとみなす旧スクリプトで一括再生成しない。新しい録音IDと本文・訳の対応を登録してから参照を追加する。

改訂版は528例題。後続の音声追加で既存448例に加え新規80例にも録音を用意し、全528例が音声付き。例題数は、教材内の追加用例や活用表とは別に数える。LP・ストア説明・スクショの714文という旧数値は実際の配信状態に合わせて更新する。
