# 文法教材の再設計方針

## 決定の範囲

後置詞、疑問詞、人称、活用表、例題の作り方についての配置方針。ユーザーの後続指示により教材・例題・CSV・Excel・辞書と日英配信パックへ実装。録音は変更しない。例題と旧音声の誤対応を防ぐため、音声参照に対応するアプリ2.1.4と新パックv3で配信する。

学習目標は、初学者が外部の説明を探さず、教材に出てくる基本表現と例題の組み立てを理解できること。「ネパール語の全構文を一章で網羅」とはせず、本教材で必要な項目の説明漏れをなくす。

## 基本人称と活用の扱い

通常の例題は次の6区分を基本にし、全区分を各テーマに機械的にそろえる必要はない。

| 日本語の区分 | 基本にする形 | 方針 |
|---|---|---|
| 私 | म | 通常の例題で使用 |
| 私たち | हामी | 通常の例題で使用 |
| あなた | तपाईं | 丁寧な呼び掛けを基本にする |
| あなたたち | तपाईंहरू | 複数への丁寧な呼び掛け |
| 彼・彼女 | उनी | 性別を固定して訳さず、文脈で区別。動詞の敬意・性の形を教材で説明 |
| 彼ら・彼女たち | उनीहरू | 必要な場合だけ性別を明示 |

तँ、तिमी、तिमीहरू、उ、उहाँ、उहाँहरू等の距離感・敬意と対応する活用は、既存テーマ7「人称と敬語」でまとめる。तिमीを単純に「目下専用」「低頻度」と断定しない。学習者が最初に使う丁寧な形を優先するという編集方針とする。複数形や敬意の高い形が不要になるわけではない。

### テーマ7で必ず説明する उ と उनी の違い

- उ（ウ）とउनी（ウニ）は、男性・女性を分ける代名詞として教えない。「उ＝彼、उनी＝彼女」という固定対応を避ける。
- 主な違いは、その人への敬意や親しさ・距離感。उは敬意の低い形、उनीはそれより敬意のある形として、使う相手・場面とともに説明する。
- 高い敬意を示すउहाँも並べ、उ・उनी・उहाँの違いを比較する。
- 代名詞の違いが動詞の形にも関わることを、हो・छ・動作動詞の対応表で示す。性を示す動詞形は、代名詞自体の性別とは分けて説明する。
- उनलाई・उनको・उनलेと、उसलाई・उसको・उसलेの対応も、後置詞が付く際の形として示す。उनीहरूको等、複数形と混同しない。
- 説明用には同じ内容を使う最小限の比較を置く。通常の練習例題では同文の活用差し替えを大量に繰り返さない。
- 日本語・英語の教材で同じ区別を説明する。

- テーマ1にहोの基本6人称の肯定・否定・疑問の作り方と活用表を載せる。
- テーマ2にछの基本6人称の肯定・否定・疑問の作り方と活用表を載せる。
- テーマ3は状態を述べるछの用法を説明し、テーマ2の表を参照する。
- テーマ4はहुन्छとछの違いを説明し、必要な形を表で示す。
- थी/थियो系を含む過去、現在、未来、完了等は、各時制テーマに必要な基本活用表を載せる。
- हो・छの全人称・敬意・性・数の参照表は付録Bにも置く。付録だけに説明を追い出さない。
- その他の動詞の体系的な活用は付録Aで参照できるようにする。
- 活用表の穴を、同じ例文の人称差し替えで埋めない。対比が学習目的のときだけ、同じ文型の比較を使う。

## 後置詞と関連表現の配置

格標識、後置詞、名詞と組み合わせる位置・時間の表現を学習対象として整理する。同じ語が単独では副詞として働く場合は区別して説明する。複合形は生産的に作れるため、下表を管理対象の一覧とし、新しい形を例文へ追加するときは説明先も必ず登録する。

| 表現 | 学ぶ意味・範囲 | 主に説明する場所 |
|---|---|---|
| मा | 場所・時点・場面の「〜に・で」 | テーマ5 基本 |
| लाई | 渡す相手、対象、経験者などの「〜に・を」。日本語と一対一で置換しない | テーマ5 基本。必要・感情の文は21・22から参照 |
| को・का・की | 所有・所属の「〜の」、後ろの名詞に応じた形の選び方 | テーマ5 基本 |
| बाट | 出発点の「〜から」、移動手段などの「〜で」 | テーマ5 基本 |
| देखि | 時間・場所の起点「〜から・以来」 | テーマ5 基本 |
| सम्म | 到達点・期限「〜まで」 | テーマ5 基本 |
| देखि…सम्म | 「〜から〜まで」の組み合わせ | テーマ5 基本 |
| सँग・सित・साथ | 同伴・相手。सँगを基本に、他は対応する形として紹介。साथは実際の結び付きを説明 | テーマ5 同伴と所持 |

| तिर・तर्फ・पट्टि | 方向・側。तिरには時刻のおおよその目安の用法もある | テーマ5 方向と位置 |
| माथि・तल・मुनि | 上・下・下方。名詞に続く形と単独の副詞を区別 | テーマ5 方向と位置 |
| भित्र・बाहिर | 内・外 | テーマ5 方向と位置 |

| नजिक・निर・छेउ・छेउमा | 近く・そば | テーマ5 方向と位置 |
| बीच・बीचमा・बिच・बिचमा | 間・中央。表記の違いも注記 | テーマ5 方向と位置 |
| वरिपरि・पारि・वारि | 周り・向こう側・こちら側 | テーマ5 方向と位置 |
| टाढा | 遠さ。単独の状態表現と「〜から遠い」を区別 | テーマ5 方向と位置。テーマ3に用法参照 |
| भर・भरि | 範囲全体・期間全体 | テーマ5 範囲 |
| को बारेमा・सम्बन्धमा・विषयमा | 「〜について・〜に関して」 | テーマ5 関係表現 |
| अनुसार・बमोजिम・मुताबिक・अनुरूप | 「〜に従って・〜に応じて」。基本はअनुसार、他は発展参照 | テーマ5 関係表現 |
| बिना・विना・बेगर | 「〜なしで」。表記違い・類義形は発展参照 | テーマ5 関係表現 |
| बाहेक | 「〜以外・〜を除いて」 | テーマ5 関係表現 |
| को सट्टा・को साटो | 「〜の代わりに」 | テーマ5 関係表現 |
| प्रति・विरुद्ध・विपरीत | 対象への態度・反対・逆方向など。基本用法と書き言葉の用法を区別 | テーマ5 関係表現の発展参照 |
| भन्दा | 比較の基準「〜より」 | テーマ25 |
| मध्ये | 集合の「〜の中で」。位置のबीचमाと区別 | テーマ25 |
| जस्तै・जस्तो・झैं・सरी | 類似「〜のように」。जस्तो等の形の変化も説明 | テーマ25 類似と比較 |
| अघि・अगाडि・पहिले | 時間の「〜の前に」。場所の前方との違いを説明 | テーマ27 |
| पछि・पश्चात् | 時間の「〜の後に」。名詞＋पछिと動詞の-एपछिを分ける | テーマ27。पश्चात्は発展参照 |
| भित्र | 時間の「〜以内に」。場所の内側との違い | テーマ27。位置用法はテーマ5 |
| को लागि・का लागि・निम्ति・निमित्त | 利益・目的「〜のために」。名詞の場合と動詞の-नको लागिを分ける | テーマ28。類義形は発展参照 |
| द्वारा・मार्फत | 動作主・仲介・経由などの違い | テーマ32。मार्फतの経由の基本はテーマ5から参照 |
| का कारण・को कारणले・को वजहले | 原因・理由。को/काは実際の結合として説明 | テーマ26 |
| का बाबजुद・हुँदाहुँदै | 「〜にもかかわらず」。後者は動詞由来の接続表現として区別 | テーマ26 発展 |

テーマ5は小見出しを「基本」「同伴と所持」「方向と位置」「範囲」「関係表現」に分ける。全項目を15例文に詰め込まない。必要な教材用例を増やし、練習は小節別に配分する。低優先の同義語を独立テーマにせず、対応表で学べるようにする。

## 疑問詞はテーマ6で体系的に教える

改訂前のテーマ6は、例文にあるकहिले・कति・किन・कसरी・कसले・कसलाई等についても、基本一覧や形の作り方の説明が不足。基本語、組み合わせる形、質問の作り方、答え方を教材として先に教える。

| 区分 | 教材に載せる形 | 学ぶ内容 |
|---|---|---|
| 人 | को | 誰 |
| 物・内容 | के | 何 |
| 場所 | कहाँ | どこ |
| 方向 | कता・कतातिर | どちらへ・どの方向に |
| 時 | कहिले | いつ |
| 理由 | किन | なぜ |
| 方法 | कसरी | どうやって |
| 数量・程度 | कति | いくつ・いくら・どれくらい |
| 選択 | कुन | どの・どれ。指す名詞を添える使い方 |
| 性質・様子 | कस्तो・कस्ती・कस्ता | どんな・どのような。名詞との一致 |
| 大きさ | कत्रो・कत्री・कत्रा | どれほどの大きさ。基本にकति ठूलोも対照として示す |
| 程度の詳しい表現 | कत्तिको・कति＋形容詞 | どの程度。基本との使い分け |
| 人＋後置詞 | कसलाई・कसले・कसको・कसका・कसकी・कोसँग | 誰に・誰が・誰の・誰と。को→कस-の変化と例外的な組み合わせを説明 |
| 人＋目的等 | कसका लागि・कसको लागि・कसबाट・कसको बारेमा | 誰のため・誰から・誰について。結合する形を示す |
| 物＋後置詞 | केमा・केबाट・केले・केका लागि・केको | 何に・何から／何で・何を使って・何のため・何の。動詞と場面で用法を分ける |
| 場所＋後置詞 | कहाँबाट・कहाँसम्म・कहाँतिर | どこから・どこまで・どの辺へ |
| 時＋後置詞 | कहिलेदेखि・कहिलेसम्म | いつから・いつまで |
| 個数・人数 | कति वटा・कति जना | いくつ・何人。助数表現の役割 |
| 時刻 | कति बजे・कति बज्यो | 何時に・今何時。文の作り方を分ける |
| 期間 | कति बेर・कति समय・कति दिन・कति वर्ष | どれくらいの間・何日・何年。年齢の尋ね方も含める |
| 頻度 | कति पटक | 何回。時間のकति बेलाとは区別 |
| 距離 | कति टाढा | どれくらい遠いか |
| 選択の拡張 | कुनचाहिँ・कुन-कुन | どれを選ぶか・該当するものを複数尋ねる。発展参照 |

一覧を見せるだけで終わらせない。各基本語には、読み、日本語と英語の意味、用法、短い質問、自然な答えを少なくとも一組ずつ付ける。को/कस-、कतिとकस्तो、कुनとके、कहाँとकता、किनとकसरी、疑問詞केと文頭の是非疑問のकेの違いを解説する。語順、否定疑問、肯定・否定の返答は基本から順に扱う。

テーマ6に基本と組み立ての説明を集約し、テーマ5の後置詞、7の敬意、23の一致、25の程度、27の時間、28の目的から相互参照する。最初の疑問詞教材で未習の過去形・意志形を説明なしに要求しない。

## 各テーマの教材に必要な構成

1. 何が言えるようになるか。具体的な場面を示す。
2. 新しい語・形の一覧。文字、読み、日本語、英語をそろえる。
3. 基本の語順・文の型と、各部分が何を意味するか。
4. 肯定・否定・疑問と、必要な基本活用表。
5. よく似た形との違い、間違えやすい点。
6. 異なる場面と語彙の教材用例。疑問文は返答も示す。
7. 上の説明に対応する練習問題。解答と、なぜその形になるかを説明。
8. 自分の状況に置き換える課題と参照先。

既習事項を毎回全文再掲しないが、参照先を明示し、その画面から復習できる構成にする。文法用語には普通の言葉による説明を添え、「てにをは」等の用語だけで説明したことにしない。

## 例題の編集基準

- 同じ名詞・動詞の人称差し替えを、各テーマの大部分にしない。
- 人称だけでなく、話す目的・場所・物・動作を変え、実際に使う意味の違いを練習する。
- 人称は基本6区分を教材全体で偏りなく扱う。各テーマに6人称を必ず一文ずつ並べる規則にはしない。
- 肯定・否定・疑問は、そのテーマの学習目的に合わせて配分する。
- 後置詞の練習では対象の形が実際に使われ、教材と解答でその働きを確認できること。
- 初出の文法を例題・辞書だけで済ませない。用例で必要なものは教材内で説明するか、先に学べる参照先を設ける。
- 日英は同じ構造・範囲で同期する。
- 改稿後の例文数は実数で再集計する。現行714文を維持するために、必要な学習項目を削らない。

## 実装時の確認

項目ごとに「主担当テーマ」「解説」「教材用例」「練習」「解答・解説」「辞書」「日英対応」「音声」を対応付けて監査する。例文の単純な文字検索だけで学習済みと判定しない。例：तिर्नुに含まれる文字列तिरを方向の後置詞と数えない。मेरो等の所有形と、完了形のगरेकी等も区別する。

改訂版は528例題。既存録音を使う448例と、音声なしの新規80例を区別する。教材・例題・CSV・Excel・辞書と日英配信パックを同期し、音声ファイルの内容は保持する。
