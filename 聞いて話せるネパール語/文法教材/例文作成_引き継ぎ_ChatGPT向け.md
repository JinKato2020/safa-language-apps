# 【引き継ぎ】ネパール語 文法モード v2「練習例文」作成のお願い（ChatGPT向け）

このファイルを ChatGPT に渡し、**日本語マスター `文法教材_v2_ja_ドラフト.md` も必ず一緒に添付**してください。

---

## 1. 目的・背景
- iOSアプリ「聞いて話せるネパール語」の**文法モード**を v2 に全面改訂中です。
- 文法テーマは **全34テーマ ＋ 付録A（動詞活用）＋ 付録B（繋辞活用）**。構成は `文法教材_v2_ja_ドラフト.md`（マスター）が正。
- マスターは「教える本」なので**例文が各テーマ2〜6文しかありません**。これを、学習者が繰り返し練習できる**十分な量の例文セット**に作り直したい（＝あなたへの依頼）。

## 2. お願いしたいこと（ゴール）
**34テーマ ＋ 付録A ＋ 付録B のそれぞれに、練習用の例文を作成**してください。
- マスターの文法・語彙・活用（特に**付録A/Bの活用表**）に**厳密準拠**。勝手な文法は不可。
- 成果物：**CSV 1ファイル**（下記フォーマット厳守）。これをClaudeが `コンテンツ\例文一覧.xlsx` に取り込みます。

## 3. 各テーマの中身のルール
1. **例文数の目安：1テーマ 15〜20文**（文法が薄いテーマは10前後でも可。紙幅の制約はないので「必要なだけ」。無理に揃えない）。
2. **主語（人称）を幅広く**使う：**म／तँ／तिमी／तिमीहरू／तपाईं／उ／उनी／उहाँ／हामी／उनीहरू**＋指示詞 **यो／त्यो**。1人称だけに偏らせない。
3. **肯定・否定・疑問をバランス良く**（そのテーマの文法に沿って）。
4. **ネパール語の正確さを最優先**：
   - 繋辞は3分割（**हो**同定／**छ**存在・状態／**हुन्छ**習慣・変化。否定 होइन／छैन）。過去は हो も छ も **थियो**。
   - 過去の他動詞の主語に**能格 -ले**（自動詞は付けない。習慣過去・進行・使役などは別ルール）。
   - 場所副詞 **यहाँ/त्यहाँ/कहाँ は -मा を付けない**。所有は **-सँग ＋ छ**。
   - 人称ごとの活用は**付録A（動詞 गर्नु）・付録B（हो/छ/थियो）の表に従う**。
5. **語彙は日常・初学者向け**（マスターに出る単語を優先。固有名・難語を増やさない）。
6. **付録A・付録B も「例文形式」で作る**（ユーザー決定済み）。活用表の各活用形を使った短い例文を、全人称ぶん作ってください（例：付録B なら「म … हुँ／तँ … होस्／…」のように各人称1文ずつ＋否定・過去も）。

## 4. 出力フォーマット（厳守・Excel取り込み用）
**CSV（UTF-8・カンマ区切り・ヘッダ行あり）を1ファイル**。列は**この順番・この列名**で固定：

```
theme_no,theme_title,no,ne,roman,ja,en
```

| 列 | 意味 | 例 |
|---|---|---|
| `theme_no` | テーマ番号（1〜34、付録は `A`／`B`） | `1` |
| `theme_title` | テーマ名（マスターの「」内） | `हो：AはBだ（同定・断定）` |
| `no` | そのテーマ内の通し番号（1から） | `1` |
| `ne` | ネパール語（デーヴァナーガリー、文末 。=।、疑問は ?） | `यो सुन्तला हो।` |
| `roman` | ローマ字読み（下の表記ルール） | `yo suntalā ho` |
| `ja` | 日本語訳（自然な口語） | `これはミカンです` |
| `en` | 英語訳（自然な口語） | `This is an orange.` |

- **ローマ字ルール**：長母音 **ā/ī/ū**、鼻母音 **ã/ũ/ẽ/õ**、ṭ/ḍ/ṇ/ś/ṣ（反り舌・歯茎）。マスターの roman 表記に合わせる。
- **CSVの注意**：セル内にカンマや改行が入る場合は **ダブルクオートで囲む**（`"…,…"`）。先頭にヘッダ行。文字コードは **UTF-8（BOMなし）**。
- **太字記号（`**`）は入れない**（マスターの例文にある `**…**` は外してプレーンなネパール語にする）。

## 5. テーマ一覧（この順・この番号で。タイトルはマスター「」内を使用）
1 हो（同定）／2 छ（存在・所在・所有）／3 छ（形容詞・状態）／4 हुन्छ（習慣・変化）／5 後置詞／6 疑問詞／7 人称と敬語／8 動作動詞の現在／9 現在の否定／10 現在進行／11 能格ले と過去／12 過去の否定／13 未来／14 習慣過去／15 現在完了・経験／16 過去完了／17 依頼・命令／18 勧誘・意志／19 禁止／20 可能／21 義務・許可／22 願望／23 形容詞の一致・位置／24 副詞＋感嘆／25 比較・最上級／26 接続／27 〜ながら/〜てから／28 〜ために／29 関係節(-ने)／30 条件／31 推量・意見・可能性／32 受動／33 使役／34 間接話法
＋ **付録A 動詞活用（गर्नु 全人称）** ／ **付録B 繋辞活用（हो・छ・थियो 全人称）**

## 7. 納品と、この後の流れ
1. **CSV 1ファイル**（上記フォーマット、全34テーマ＋付録A/B）を納品。
2. これをユーザーがClaudeに渡す → **Claudeが `コンテンツ\例文一覧.xlsx` に「v2文法例文」シートとして取り込む**。
3. その後の**音声はClaudeが生成**します（ChatGPTは音声不要・テキストのみ）：
   - ネパール語＝Azure **ne-NP-HemkalaNeural（女性・標準速度）**
   - 日本語＝Google ja-JP-Neural2-B／英語＝Google en-US-Wavenet-F
4. 完成後、**ネパール語話者による最終確認を推奨**（マスターもAI作成のため）。

## 8. 品質上の注意（再掲）
- **文法の正確さ＞量**。自信がない活用は付録A/Bの表に必ず戻って確認。
- 不自然なヒンディー寄り表現を避け、**ネパール語として自然な口語**に。
- 日本語・英語は**平易で自然**に。
