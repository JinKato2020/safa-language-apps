# ネパール語学習辞書

正本は `nepali_dictionary.json`。ホームの「ネパール語辞書」から開く。JA/EN両UIで4言語表記を検索できる。辞書項目は学習用の語義であり、網羅辞典ではない。

## 作成・更新

1. `scripts/build_nepali_dictionary.py` と `scripts/dictionary_basic_expansion.py` の読み・修正語義・追加見出し・活用・用例を編集する。
2. `python -X utf8 -B scripts/build_nepali_dictionary.py` で既存単語1,000行を統合し、辞書と両言語オーバーレイを更新する。
3. 音声が増える場合のみ、既存の `node scripts/generate_learning_audio.mjs` を実行する。Azure Hemkala・標準速度。同一テキストの既存音声は再利用し、教材・文字の承認済み音声も保持する。
4. 再び辞書生成を実行して、音声参照を両オーバーレイに同期する。
5. `node scripts/verify_nepali_dictionary.cjs`、`node scripts/verify_content_ota.cjs`、必要時は `python -X utf8 -B scripts/verify_learning_audio.py` で検証する。
6. 既存の `publish_content_ota.ps1` で公開する。辞書対応アプリの導入後は、語義・活用・用例・音声の追加にネイティブ再ビルドは不要。

既存の文脈辞書の機械生成訳は見出し語の意味として自動採用しない。`sources` の `カテゴリ:行` は元の1,000行への参照。独立追加語は `カテゴリ:dictionary:安定ID` と区別し、同じカテゴリフィルターで表示する。元データの行数に追加語を混ぜない。`forms` は確認した活用形・綴りの異形だけ。未知語の語尾を切って基本形を推測しない。`themes` は実際に当該語が載る教材へのリンク。用例は全文を確認した短文のみを載せる。ローマ字は綴りに対応した読みの補助であり、IPAではない。

## レビュー記録（2026-11-08）

元の1,000行のネパール語・日英の対応を全件確認し、重複・文脈に狭すぎる訳・品詞の違いを整理。基本動詞や代名詞・後置詞を補った。特に甥／いとこ、縫製／仕立て屋、記憶／命日、茶色／灰色、食べ物／デザートなどの誤対応を修正した。ソースの行番号は保持し、既存クイズをこの辞書から再生成する処理は行っていない。

曖昧な語義・綴りは [シカゴ大学DSAL公開の現代ネパール語辞典](https://dsal.uchicago.edu/dictionaries/schmidt/) も個別照合した。例：परेला はまつげ、छत は平らな屋根、फ्याउरो はキツネ、बासना は香り、ससुरा は義父。辞典本文・用例の一括取得や転載はしていない。日本語・英語の説明と本アプリ用例は独自に記述した。

現地話者による全見出し・音声の監修は未実施。機械音声のファイル整合性・再生形式検証と、発音の聴覚的な正しさの確認は区別する。今後の訂正は正本と音声をセットで更新する。

## 2.2.3 の基本語拡充（2026-11-08）

見出し語を988語から2,089語へ拡充。活用形・表記異形542件は見出し語数に数えず、用例は52件。日常動詞、状態・程度、人物・体、食事・家事、数・時刻、仕事・通信、場所、接続・関係表現などを追加した。元の988語のIDは維持し、クイズの1,000行は変更していない。

मर्नु（死ぬ）と मार्नु（殺す）、फाल्नु（捨てる・投げる）と छोड्नु（離す・置いていく）、देख्नु と हेर्नु、चाहनु と चाहिनु などは短い日英の使い分けを追加。捨てるで फाल्नु が検索できる。छ は数字6の見出し語と हुनु の活用を区別する説明を追加した。

追加語義・読みを全件読み合わせ、重複・低頻度の水増し・単なる活用形の見出し化を整理した。曖昧な基本動詞は前掲DSALで照合。用語の表記確認には[ネパール中央銀行の विनिमय दर](https://www.nrb.org.np/category/faqs/faq_fxm/faq_fxm-others/)、[農業行政の खुर्पानी](https://suryabinayakkrishi.gov.np/fruit-farming-technology-info/1649)、[職業訓練教材の स्याम्पु](https://vsdta.gov.np/uploads/publications/documents/%E0%A4%B5%E0%A5%8D%E0%A4%AF%E0%A5%81%E0%A4%9F%E0%A4%BF%E0%A4%B8%E0%A4%BF%E0%A4%AF%E0%A4%A8.pdf) も参照した。これらの本文は転載していない。現地話者による監修と全音声の聴取は引き続き未実施。

ホームの4カードは2×2・短いタイトルのみとし、不要な誘導文と達成文句を削除。「Small steps build great strength.」を色とサイズで強調した。ホームUIは2.2.3のネイティブ更新、辞書データと音声はOTA 1223でも配信する。
